# 02_大纲

## 一、故事总纲

宁烬一直没放下陈野之死。武考第一对他从来不是终点，而是让他被看见、被忌惮、被纳入核心视线的门票。夺魁第一夜，城市裂口暴走，他在生死间觉醒体内禁忌残印，也在那一夜第一次强烈怀疑：陈野那次根本不是孤立事故，武考第一夜的异常很可能和旧案出自同一套规则。自此，他同时被学院甜系校花苏清软、守夜女队长沈夜璃、异端圣女祁雪祀从三种完全不同的立场盯上。后续学院与守夜双线，不再只是他上位的舞台，而是他一边查案、一边被拦截、试探、利用的双重场域；白天抢资源、抢名额、抢入口，夜里踩任务、踩裂口、踩进和陈野相似的死路。

## 二、卷一总目标

### 1. 明线目标

- 宁烬要查清陈野之死究竟是不是事故，以及它和武考第一夜异常是不是同一套规则
- 前二十章必须不断让读者看到：宁烬接下来是在顺着旧案往下追

### 2. 手段目标

- 宁烬必须在卷一内完成从“武考第一的风口人物”到“学院与守夜都不敢随手拿捏的危险核心”的身份跃迁
- 他要拿下学院核心培养席位与守夜预备资格，因为不抢到这些位置，他根本没有继续查下去的资格

### 3. 黑幕目标

- 卷一结尾必须拿到第一份能指向守夜局高层的铁证，但只撕开一角，不一次掀底

## 三、世界承重结构

### 1. 小世界战场

- 卷一主要缠斗空间是这座边境大城内部：武考体系、顶级学院、守夜局分部、城市裂口区
- 这里的冲突必须足够具体：排名、资源、名声、任务、生死、立场站队

### 2. 大世界阴影

- 城外有更大的裂口群、荒域战场、守夜总体系与异端网络
- 这座城并不是世界中心，它只是更大冲突链条上的一个试验场和筛选场
- 卷一不讲完大世界，但要不断让读者感觉“这城里发生的事，只是外面巨浪压进来的一角”

### 3. 小世界与大世界的投影关系

- 学院里的资源争夺，对应的是更高层对战力与天才的抢夺
- 守夜任务里的异常安排，对应的是更大层级的养灾控灾工业链
- 宁烬身上的残印，不只是个人秘密，而是大世界旧实验链留下的活体回声

## 四、故事承重结构

### 1. 表层故事

- 不是“危险少年一路上位”，而是“危险少年为了查旧案，被逼着一边上位一边踩进更深的局”
- 白天他要在学院体系里抢资源、抢名额、抢接近真相的资格，夜里他要在守夜任务里撞见越来越像陈野旧案的死路
- 他每一次更高调地出头，都会更接近真相，也会更快被学院、守夜和幕后黑手同时盯死

### 2. 深层故事

- 陈野之死不是已经翻页的往事，而是一条还在继续运转的规则链留下的血痕
- 城市里的神灾异常并非单纯失控，第一夜裂口和旧案背后很可能是同一套筛人、养灾、控灾机制
- 主角的残印来源，与守夜局内部的一段旧实验链高度相关，而这条链正是宁烬追查旧案时不断逼近的核心黑幕

### 3. 情绪承重

- 爽：压人、碾压、立功、抢资源、越级反杀
- 狠：尸体、污染、异化、背刺、体制肮脏
- 热血：守夜、护城、少年不退、队伍战
- 欲望与关系：三女围绕主角的争夺、牵制、保护与诱引不断升级

## 五、核心角色结构

### 1. 主角：宁烬

- 关键词：武考第一、禁忌残印、越强越失控
- 功能：
  - 爽点提供者
  - 真相线入口
  - 关系网中心

### 2. 学院核心女主：苏清软

- 关键词：甜软、善良、护人、童颜丰润、旧功勋名门
- 功能：
  - 学院线的人性锚点
  - 女生冲突线的核心支点
  - 负责把宁烬从“像怪物”往“还像人”那边拉

### 3. 守夜女队长：沈夜璃

- 关键词：秩序、掌控、冷、强压制力
- 功能：
  - 夜里守夜线的主要牵引者
  - 代表官方力量对主角的利用与戒备
  - 负责“压他 / 保他 / 用他”的复杂关系

### 4. 异端圣女：祁雪祀

- 关键词：危险、美、异端、理解主角失控面
- 功能：
  - 代表黑暗一侧的诱惑与真相
  - 最懂主角为何会失控
  - 负责敌我不明和危险吸引

### 5. 学院派对立组

- 裴承泽：资源与身份压制
- 温知白：舆论与伪善捅刀
- 乔念薇：女学生圈层带节奏、恶心人、挑起对立
- 林可依：旧执念型绿茶女，负责开篇切断男主过去的“舔狗认知”

### 6. 守夜派对立组

- 陆沉锋：前线冷血派，负责把宁烬逼进真正见血的死局

### 7. 幕后黑手组

- 邢观潮：守夜局高层黑手，负责把学院、守夜、灾区异常串成一条更大的阴谋链

## 六、卷一三层冲突升级图

### 1. 学院派冲突

- 负责贬低、看不起、欺诈、资源封锁、舆论羞辱
- 功能不是简单给主角喂经验，而是逼苏清软、贺奔等角色站出来，形成群像互动和女主发挥空间

### 2. 守夜派冲突

- 负责正面战场、任务搏杀、生死压迫
- 功能是给宁烬制造真正能见血、能立威、能爆高光的硬局

### 3. 幕后派冲突

- 负责把学院派和守夜派表面的冲突往更深的黑幕串联
- 每一次“小人作恶”和“任务异常”背后，都要隐约通向更大的养灾筛人体系

## 七、三女第一次强记忆点出场

### 1. 苏清软

- 医务区初登场
- 她半跪在浑身是血的宁烬面前替他处理伤口，脸是幼态甜感，眼神却稳得出奇
- 宽松校服和针织衫也压不住她过分丰润的曲线，但她说话很软，做事却一点都不软
- 当学院派想趁机偷拍视频、带节奏时，她第一次当众护住宁烬，把“甜”“软”“护短”一次立住

### 2. 沈夜璃

- 灾区高架初登场
- 黑色作战服束出凌厉腰线与长腿，眉眼冷利，像一把刚出鞘的薄刃
- 她站在裂口风压最猛的地方单刀封街，几句话就把全场压到不敢乱动
- 她看宁烬的第一眼不是心动，而是判断这人该不该纳入控制

### 3. 祁雪祀

- 裂口废墟初登场
- 肤色冷白，身段妖冶，腰细腿长，像从污染月色里走出来的异端祭品
- 她踩着满地碎玻璃和血水出现，笑意慵懒，却一句话就点穿宁烬体内残印的异常
- 她看宁烬的第一眼不是欣赏，而是确认自己找到了一件足够有趣也足够危险的猎物

## 八、卷一主要高光场面分配

### 1. 宁烬

- 武考第一夜，在裂口暴走与后续筛选中被逼暴露残印异常，先从“武考天才”变成“危险样本”，并在第一轮真正下场前确认自己已经踩进和陈野相似的路
- 卷末在学院实战与守夜死局叠加的局面中，顶着人格污染狠狠干穿围杀，把铁证从死人堆里抢出来

### 2. 苏清软

- 学院公开场合顶住温知白和乔念薇的节奏攻势，第一次证明她不是花瓶软妹
- 宁烬濒临暴走时，她顶着封锁线冲进去把人拽回来，成为主角人性仍未断掉的最强证明

### 3. 沈夜璃

- 前期独自封住一次裂口蔓延，立住她在守夜线的绝对压制力
- 卷末在上级施压下强行改判任务优先级，为了保宁烬第一次明着违令

### 4. 祁雪祀

- 前期以极其危险的方式替宁烬解掉一次精神污染反噬，让主角第一次见识她的价值和危险
- 卷末在裂口深层反手处理掉一个抢夺宁烬的异端节点，顺势抛出更大真相

### 5. 贺奔

- 在实战中顶着重伤护住普通学员和宁烬后背，补强兄弟热血线

### 6. 裴承泽

- 在学院大场面里摆出资源与身份羞辱局，再被宁烬狠狠干碎脸，形成白天线爽点

### 7. 温知白与乔念薇

- 一明一暗发起舆论围猎和情绪围剿，把学院线做成不是只靠打架推进的复合冲突

### 8. 陆沉锋

- 在前线把宁烬当污染兵器往死局里塞，逼出主角最硬的一次战场高光

### 9. 邢观潮

- 卷末只露出一角，但这一角必须足够狠，足够让读者意识到真正的大 boss 还在更上面

## 九、故事推进节点

### 第一幕：武考第一夜点火，旧案复燃

#### 关键任务

- 立主角：能打、够狠、不是普通热血少年
- 立反差：外界还以为宁烬会像以前一样围着林可依转，但开篇就要证明他已经清醒
- 立世界：城市表层正常，暗层神灾渗透，小世界之外还有更大的战场
- 立三女：苏清软、沈夜璃、祁雪祀都要在前期开出存在感，而且盯上动机不同
- 立旧案：第一夜除了点火，还必须把“旧案重新活过来”立住，让陈野之死不再只是背景设定
- 立钩子：残印觉醒，主角第一次人格污染，并从异常细节里怀疑陈野那次不是孤立事故

#### 核心事件

1. 宁烬在武考中强势夺魁
2. 当夜城市局部裂口暴走，名单开始挑人
3. 宁烬在控场区被扣成危险样本，第一次正面看见学院与守夜两套口径共用同一套筛选结构
4. 官方通报和现场真实情况出现裂缝，宁烬开始顺着东三区转运名单、调度回执去怀疑陈野之死不是孤立事故
5. 苏清软、沈夜璃、祁雪祀分别从人性、秩序、异端三个方向注意到他
6. 低位者先填命的模板落地，宁烬确认自己不能把武考第一当成终点，而要把它当成继续查陈野旧案的入场券
7. 第五章结尾，东门转运舱失联，他被强征下场，第一轮真正点火开始

### 第二幕：白天抢资格，夜里踩旧路

#### 总驱动

- 学院线和守夜线不是各跑各的，而是同一件事的两种推进方式：白天抢接近真相的资格，夜里踩进和陈野相似的死路
- 学院特招、核心培养席位、守夜观察资格都不是奖励，而是宁烬继续查旧案必须抢到的入口
- 东三区当夜的转运名单 / 调度回执，要成为前段最具体的追查抓手；宁烬要想办法把它和陈野旧案的封存任务记录对上

#### 白天线

- 宁烬进入顶级学院资源争夺
- 裴承泽、温知白、乔念薇、林可依开始从身份、规则、舆论、情绪和旧关系认知五个层面围杀他
- 苏清软作为旧功勋名门苏家的嫡女，她的站队会被学院圈层自动放大成“高门到底选谁”的风向
- 苏清软逐渐站到宁烬这一边，成为学院线的重要护盘角色
- 贺奔成为宁烬在白天线少数能并肩的人
- 宁烬越来越清楚：如果拿不到学院内部被认真对待的位置，他连查阅、接触、旁听异常信息的门槛都过不去

#### 夜里线

- 沈夜璃把宁烬以半观察、半利用方式拉进守夜任务
- 陆沉锋不断把他推向“能赢但不正常”的死局
- 祁雪祀开始通过暗线接触主角，试探他的残印来历和失控边界
- 每一次夜间任务都像是在把陈野旧案重演一遍，让宁烬开始从任务流程、封锁规则和伤亡模板里拼旧案真相
- 他会反复盯住东三区当夜的转运名单、调度回执和对应任务流向，确认第一夜到底是不是被人按模板送进死局

### 第三幕：旧案与异常第一次并线

#### 关键目标

- 主角不只是发现外部敌人
- 而是明确意识到：守夜局内部有人在筛选、养成、利用类似他这样的异类，陈野旧案正是这条链上的前案

#### 核心事件

1. 某次任务中，宁烬发现本该被提前封锁的灾区却被故意放开
2. 有一批“正好适合残印者成长”的污染体被投放到任务区域
3. 沈夜璃察觉不对，但无法直接对高层动手
4. 苏清软和贺奔在学院端先后踩到异常资源流向
5. 祁雪祀暗示：你不是第一个被这样养出来的人
6. 宁烬第一次摸到能调取陈野旧案封存任务记录的入口，并确认东三区当夜的转运名单和旧案之间存在可并线的编号痕迹

### 第四幕：第一卷高潮

#### 核心结果

- 主角在学院层面完成第一次大上位，拿到继续追查旧案的硬资格
- 同时在守夜任务中拿到铁证，证明守夜局内部有人在养灾控灾，陈野旧案背后不是偶发事故
- 但真正的大人物没有倒下，只露出一角

#### 高潮事件设计

1. 学院重大考核与城市联合实战重叠来临
2. 学院派借公开场合做局，守夜派借实战顺手清理不可控对象
3. 宁烬在几乎彻底人格污染的边缘完成反杀
4. 苏清软顶着风险把他从失控线边缘拖回来
5. 沈夜璃被迫站队，并第一次明显违逆体制命令
6. 祁雪祀正式把更大的真相抛到主角面前
7. 邢观潮只露出一角，却让读者意识到上面还有更大的手

### 第一卷收束

- 主角赢得继续追陈野旧案的阶段性地位
- 三女关系全部进入新的危险平衡
- 学院派和守夜派都确认宁烬已经不是能随意揉捏的人
- 守夜局黑幕被撕开一角
- 主角知道自己继续查下去，就再也回不到普通学院天才的轨道

## 十、前三十章粗分配

### 1-3 章

- 武考夺魁
- 第一夜裂口与名单挑人
- 官方口径裂缝和同一套筛选结构露出来
- 陈野旧案的伤口被重新掀开

### 4-10 章

- 三女全部入场
- 学院特招与守夜观察同时开始
- 宁烬意识到自己现在还没有资格查，只能先抢名额、抢位置、抢入口
- 他先盯上东三区当夜的转运名单 / 调度回执，试图确认第一夜的幸存、转运、封锁到底是谁签批
- 他开始拿第一夜的签批模板、任务编号和被优先送死的人去对照陈野旧案，确认两边是否出自同一种安排
- 林可依试图拿旧关系重新吊住宁烬，结果被他当众切断
- 学院派第一次集中恶心他，苏清软第一次站出来护盘
- 苏家嫡女的站队传开后，学院对宁烬的敌意明显加码

### 11-20 章

- 学院资源争夺
- 小型守夜任务
- 第一夜异常与旧案模板第一次明确重叠
- 主角第一次摸到可对照的陈野旧案记录入口，知道该去找哪一份封存任务记录
- 学院端 / 守夜端先后吐出可以并线的名单、日志或封存记录线索，让东三区当夜调度回执不再只是猜测
- 祁雪祀暗线试探
- 陆沉锋第一次把宁烬往死局里送
- 宁烬决定顺着这条线继续查下去

### 21-30 章

- 守夜局内部疑点加深，宁烬开始围绕陈野旧案反向拼接任务流程和可疑人员
- 学院派围杀升级
- 沈夜璃明显进入“既想保他又想控制他”的阶段
- 苏清软确认自己不会从宁烬这边退开
- 主角确认自己不是偶然沾上残印，而是被某条与陈野旧案相连的旧链条盯上

## 十一、三大 Turning Points

### Turning Point 1

- 武考第一夜，裂口暴走与筛选结构同时露面
- 第一夜裂口把陈野旧案重新激活，主角先从“武考天才”变成“被盯上的危险样本”，并在第五章末被推向真正下场的入口

### Turning Point 2

- 宁烬拿到第一条能把第一夜异常和陈野旧案并线的明确记录入口：东三区当夜的转运名单 / 调度回执，指向陈野旧案的封存任务记录

## 十二、长线升级与关系设计

### 1. 升级逻辑

- 武考体系 -> 学院资源 -> 守夜实战 -> 裂口深层 -> 城市级危机 -> 更大荒域战场

### 2. 黑幕推进逻辑

- 小异常 -> 任务安排不对 -> 案件重复模板 -> 人为养灾证据 -> 高层牵连 -> 更上层总体系

### 3. 感情推进逻辑

- 苏清软：心疼 -> 护短 -> 不退 -> 占位
- 沈夜璃：审视 -> 利用 -> 压制 -> 保护
- 祁雪祀：试探 -> 引诱 -> 共鸣 -> 危险纠缠

## 十三、进入后续阶段前必须保留的东西

- 宁烬不是正统英雄模板，而是危险成长型主角
- 苏清软、沈夜璃、祁雪祀三人的“盯上动机”绝不能写成同一种
- 守夜局黑幕必须前置埋线
- 人格污染必须是明确代价，而不是装饰设定
- 卷一目标必须始终明确，不许写成只有事件没有方向的散点推进
- 小世界的每一次冲突都要能映出更大的世界阴影
