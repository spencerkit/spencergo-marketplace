# 01B_总主线与卷级推进

## 一、总主线一句话

宁烬为了查清陈野之死，先借武考第一撕开上升通道，再一路抢进学院核心与守夜体系；他在追查第一夜异常和旧案重叠的过程中，逐步撕开守夜局养灾控灾、筛样本和旧实验链的黑幕。

## 二、整本书的四条承重线

### 1. 上位线

- 从武考第一的风口人物，变成学院核心、守夜重点战力、城内不可忽视的异类核心
- 每一卷都必须有“宁烬从被拿捏到让别人不敢碰”的身份变化

### 2. 黑幕线

- 从一座城的异常任务安排，追到守夜局分部，再追到更高层旧实验链与总体系利益链
- 每推进一步，都要让读者感觉敌人不是单个坏人，而是一整套吃人的秩序

### 3. 关系线

- 苏清软负责把宁烬往人那边拽
- 沈夜璃负责把宁烬绑在秩序与控制线上
- 祁雪祀负责把宁烬往黑暗真相里引
- 其他女性角色可扩张，但必须服从这三条主关系线，不许乱抢主位

### 4. 代价线

- 残印越强，污染越重
- 宁烬越接近真相，越被体制盯死
- 他越想护住身边的人，越会被逼着付出更痛的代价

## 三、卷级发动机

### 卷一发动机

- 目标：查清陈野之死是否真是事故，并确认第一夜异常和旧案是不是同一套规则
- 手段：成为这座城里谁都绕不过去的人，抢到学院核心培养席位与守夜预备资格
- 情绪：开局点火，学院围杀，守夜死局，三女盯人，黑幕初露
- 收束：宁烬拿到第一份能指向守夜高层的铁证，同时确认自己继续查下去就等于踩进更大的筛人链

### 卷二发动机

- 目标：顺着卷一铁证往上追，进入学院更核心区与守夜正式体系
- 重点：旧实验链、残印样本、苏家旧档案、沈夜璃压着不说的旧任务
- 收束：证明本城不是特例，而是整条筛选链的一环

### 卷三发动机

- 目标：走出城市安全壳，进入更大的裂口战区和荒域边界
- 重点：宁烬从“城内危险天才”变成“外域也要抢的人”
- 收束：打掉一个足够分量的台前大人物，但发现真正的总控制权不在他手里

### 卷四发动机

- 目标：撕开总体系和异端网络之间更深的共谋
- 重点：祁雪祀身后的旧实验链、降神容器、残印真正来历
- 收束：宁烬必须在“成为更强的武器”和“保住自己是人”之间做更残酷的选择

### 卷五发动机

- 目标：把局从个人复仇和局部揭黑，推进到真正改写秩序
- 重点：更大范围的裂口战争、总体系清洗、后宫与兄弟线在大局中的站队
- 收束：完成主角从“被挑选的样本”到“反过来挑翻规则的人”的终极跃迁

## 四、卷一到长线的推进链

### 1. 明线推进链

- 陈野之死的疑点
- 武考夺魁
- 学院核心培养席位之争
- 守夜预备资格
- 第一夜与旧案模板重叠
- 城级危机里拿铁证

### 2. 暗线推进链

- 裂口任务安排异常
- 污染体投放有模板
- 守夜局分部在筛样本
- 更高层旧实验链浮出水面

### 3. 感情推进链

- 苏清软：心疼 -> 护人 -> 公开站队 -> 卷一站稳位置
- 沈夜璃：观察 -> 控制 -> 保人 -> 违令
- 祁雪祀：试探 -> 引诱 -> 共鸣 -> 抛真相

### 4. 后宫扩张规则

- 卷一主心骨仍然是三女
- 后续新增女性角色只能作为补充层：
  - 学院侧
  - 守夜侧
  - 异端侧
  - 荒域侧
- 新增必须满足：
  - 能带新战线
  - 能带新冲突
  - 能放大主角抉择

## 五、主角驱动力总合同

### 1. 最表层驱动

- 查清陈野到底怎么死的

### 2. 现实手段驱动

- 变强
- 上位
- 抢资格

### 3. 更深层驱动

- 把把人命当材料的那套规则狠狠干烂
- 不让陈野式的死继续落到自己人头上

### 4. 绝不能丢的底层句子

- 我可以烂，但我身边的人不能再死

## 六、代价体系总合同

### 1. 力量代价

- 残印爆发会加深人格污染
- 污染不是掉一点血，而是会让宁烬越来越像一件效率优先的兵器

### 2. 社会代价

- 体制会盯上他
- 学院会防备他
- 人会怕他，也会想利用他

### 3. 关系代价

- 苏清软会因此承压家族与学院眼光
- 沈夜璃会因此在体制内失去站稳的余地
- 祁雪祀越靠近他，越会把他往深水里拖

## 七、必须反复兑现的阅读承诺

- 每一卷都要有硬战场高光
- 每一卷都要有至少一次关系线强碰撞
- 每一卷都要撕开更大黑幕的一层皮
- 每一卷都要让宁烬付出真实代价，而不是白拿升级

## 八、卷一不能丢的承重点

- 前三章必须点火
- 前十章必须建立阶段目标
- 前二十章必须让读者确认主角不是在做零散任务，而是在往大黑幕走
- 林可依这条旧关系线必须在开篇就切断，不能拖泥带水
- 苏清软的高门站队必须变成学院线的真实冲突
- 卷一结尾必须拿到铁证，但不能把更大的幕后一次讲光
