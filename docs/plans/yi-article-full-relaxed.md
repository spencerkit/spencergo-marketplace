# 六爻铜钱起卦：我是如何把传统文化「装进」Claude Code 的

---

**一个程序员的"迷信"时刻**

---

事情是这样的。

作为一个天天写代码的程序员，你一定经历过这种时刻：需求改了第八遍，第九遍又来了，产品经理在群里疯狂@你，说"这里再调一下"。

你盯着屏幕，心里默默算了一下：这周已经加班到凌晨三点了三次，而这个月的需求排期表上，还有四页没完成。

那一刻，你脑子里突然冒出一个问题：**我TM到底什么时候才能不这么苦逼？**

不是开玩笑，是真的想知道。

但问题来了——你不会算卦啊！

于是你打开了 Claude，试着输入："帮我算一卦，看看我什么时候能转运。"

三枚虚拟铜钱抛下，屏幕跳出：**巽为风卦。**

你对着屏幕发了会儿呆，心想：这也没告诉我什么时候能发财啊......

不行，这届 AI 不太行，**我得让它变得更专业**。

然后就有了这篇文章的故事。

---

**动机：为了方便摸鱼算卦**

---

动机其实特别简单。

作为一个程序员，你一定懂这种感受：下午三点，需求改累了，代码跑不通了，脑子转不动了——但又不能真的去刷抖音，毕竟老板还在身后走来走去。

这时候，如果能"摸鱼"十分钟，顺便满足一下好奇心，岂不是完美？

但问题是：

- 拿手机查星座运势？太不专业了
- 去网站算一卦？那个界面真的是......上世纪的，感觉穿越了
- 问 Claude？它倒是能聊，但让它正经算一卦，它就开始和你讨论"量子力学"了

**我就是想：打开 Claude，摇一卦，然后继续干活。**

就这么简单。

于是就有了这个技能。

---

**实现：我是怎么让 AI 帮我算卦的**

---

说出来你可能不信，这整个技能我只花了一个下午。

就三步，轻轻松松：

**第一步：让 AI 帮我整理数据**

六十四卦这玩意儿听着就复杂，其实就是 8 个基础卦两两组合。我让 AI 帮我从网上扒拉下来，存成一个 JSON 文件——卦名、卦辞、爻辞、六亲世应，全部整理得明明白白。就跟做数据清洗差不多，简单得很。

**第二步：模拟摇铜钱**

这可能是整个技能里最"玄学"的部分。

三枚铜钱抛下去，有四种可能：
- 三个正面 → 老阴（动，变阳）
- 三个反面 → 老阳（动，变阴）
- 两个正面 → 少阳（不动）
- 一个正面 → 少阴（不动）

摇六次，从下往上数，就是一个完整的卦。

代码就这么多，别被吓到：
```javascript
function yaoGua() {
  const coins = Array(3).fill(0).map(() => Math.random() > 0.5 ? 1 : 0);
  const heads = coins.reduce((a, b) => a + b, 0);
  // 3正=老阴, 0正=老阳, 2正=少阳, 1正=少阴
  // ...返回对应结果
}
```

没错，就是这么几行代码，你也能玩。

**第三步：让 AI 帮我解卦**

这才是真正的技术活。

你猜怎么着？直接让 AI 解，它能给你扯一堆"天机不可泄露"的废话，跟没回答一样。

后来我想了个办法——**喂给它足够多的上下文**。我把卦辞、爻辞、象征意义全部塞进 prompt 里，再加上一句："用文言文风格但现代人易懂的方式回答"。

然后它就开始正常说人话了。搞定！

**成果：第一版是个什么玩意儿**

---

搞完之后，我第一时间给自己算了一卦。

问题：**"我什么时候能发财？"**

三枚铜钱抛下——**困卦。**

好家伙，直接来了个"困"字，这是要闹哪样？

解卦说：目前处于困境，但坚持下去会有转机。

我：......

行吧，至少比"天机不可泄露"强。好歹给点提示不是？

至于你们用这个技能问什么，那就是你们的事了。万一问出个好卦呢？

**思考：AI 能不能算命？**

---

说实话，我也不确定。

但我想明白了一件事：**玄学这玩意儿，说白了也是一种"随机"。**

你摇铜钱，铜钱落在地上，是正面还是反面——这是随机的，谁也控制不了。
AI 生成回答，下一个词是什么——这也是随机的，碰巧而已。

两个随机撞在一起，说不定反而有奇效。万一呢？

你问我信不信卦能预测未来？

我不信。

但我信一件事：**当你迷茫的时候，有一个声音告诉你"再坚持一下"，这本身就很有力量。**

哪怕这个声音是 AI 扮演的，至少它不会嫌你烦。

至于传统文化数字化这件事——
我尽量不做"简化"。

六十四个卦，每个卦的卦辞、爻辞、六亲、世应，全部保留。
解卦的时候，不是给你一个简单的"吉"或"凶"，而是把原文喂给 AI，让它给你解释。

你能看到古人在说什么，然后 AI 帮你翻译成现代话。

这算不算"还原"我不知道，但我尽量让它不那么像"算命 app"。毕竟咱们是程序员，要有点追求。

**如何使用？**

---

简单，就两步：

**第一步：安装**

```bash
/plugin marketplace add spencerkit/spencergo-marketplace
/plugin install yi@spencerkit/spencergo-marketplace
```

复制粘贴，回车，搞定。

**第二步：使用**

直接输入：
- `/yi`
- 或者说"帮我占卜"
- 或者说"起一卦"

然后它会问你问什么问题，你直接说就行。

比如："我下周有个面试，帮我算算能不能过。"

三枚铜钱抛下，AI 开始给你解卦。完了你该干嘛干嘛去。
