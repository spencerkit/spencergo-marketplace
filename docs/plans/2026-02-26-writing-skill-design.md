# 写作技能设计文档

**日期**：2026-02-26
**主题**：写作技能 (writing)

---

## 一、概述

创建一个综合性的 Claude Code 写作技能，支持内容创作、创意写作和技术文章三大类，帮助用户快速生成各类文章初稿。

## 二、支持的写作类型

| 分类 | 具体类型 | 说明 |
|------|----------|------|
| **内容创作** | 公众号/博客文章 | 长篇文章，结构清晰，有深度，1500-5000字 |
| | 小红书笔记 | 短平快，图文结合，情感共鸣，300-1000字 |
| | 微博长文 | 观点鲜明，互动性强，500-2000字 |
| | 抖音/快手脚本 | 分镜设计，节奏快，时长15-60秒 |
| | B站视频脚本 | 知识性强，节奏适中，5-15分钟 |
| **创意写作** | 短篇小说 | 人物、情节、环境，1000-10000字 |
| | 故事/微小说 | 短小精悍，情节反转，500-2000字 |
| | 诗歌 | 现代诗/古体诗，可选韵律/意象 |
| **技术文章** | 技术教程 | 步骤清晰，代码演示，面向学习者 |
| | 技术分析 | 深度解读，原理剖析，面向同行 |
| | 技术科普 | 通俗易懂，面向非技术人员 |
| | 架构文档 | 系统设计，架构思路，面向决策者 |

## 三、写作参数

### 基础信息
- **主题**：文章核心话题
- **标题**：是否需要标题（可选）
- **字数**：目标字数

### 风格选择
- **文章风格**：严肃正式 / 轻松活泼 / 幽默风趣 / 温暖治愈 / 犀利深刻 / 叙事性强 / 议论性 / 说明性
- **语言**：中文 / 英文 / 双语
- **叙事视角**：第一人称 / 第二人称 / 第三人称 / 旁观者

### 语气调节
- **语气**：专业权威 / 亲和友好 / 俏皮可爱 / 冷静理性 / 热情激昂 / 沉稳内敛 / 讽刺辛辣 / 真诚走心
- **情感温度**：冰冷 / 温和 / 温暖 / 热烈
- **距离感**：高高在上 / 平等对话 / 亲密无间

### 结构要求
- **结构**：流水账 / 总分总 / 倒金字塔 / 清单式 / 问答式 / 起承转合
- **开头**：故事引入 / 痛点引入 / 结论先行 / 提问引入 / 悬念引入
- **结尾**：总结升华 / 呼吁行动 / 开放结尾 / 首尾呼应 / 金句点睛

### 受众定位
- **目标读者**：专业人士 / 小白用户 / 同行 / 管理者 / 大众
- **读者痛点**：读者关心什么问题
- **阅读目的**：学习 / 娱乐 / 解决问题 / 获得资讯

## 四、各类型追问流程

### A. 公众号/博客文章
必问：
1. 文章主题是什么？
2. 目标读者是谁？
3. 想要什么风格？（严肃/轻松/犀利/温暖等）
4. 大概需要多长？（1000字/2000字/3000字+）

可选：
5. 有什么特别想表达的观点？
6. 需要加入案例或故事吗？
7. 语言偏好？（中文/英文/双语）

### B. 小红书/社交媒体
必问：
1. 笔记的核心话题/主题？
2. 目标人群？（如：职场女生/大学生/新手妈妈）
3. 想要什么风格？（干货型/情感型/种草型/故事型）
4. 需要几个部分/几点？

可选：
5. 想要什么语气？（亲切/专业/俏皮）
6. 需要加emoji或话题标签吗？

### C. 短视频脚本
必问：
1. 视频主题？
2. 时长？（15秒/30秒/1分钟/5分钟）
3. 内容类型？（知识科普/剧情故事/好物推荐/搞笑段子/情感表达）
4. 目标受众？

可选：
5. 需要分镜吗？
6. 旁白还是对话形式？

### D. 故事/小说
必问：
1. 什么类型的故事？（都市/校园/悬疑/科幻/奇幻/历史/武侠/爱情）
2. 主要人物是谁？
3. 故事背景？（现代/古代/未来/异世界）
4. 大概多长？（短篇/微小说/中篇）
5. 风格调性？（热血/治愈/虐心/轻松/深刻/黑暗）

可选：
6. 需要什么结局？（圆满/开放/悲剧）
7. 有特定的情节元素想加入吗？

### E. 诗歌
必问：
1. 什么类型的诗歌？（现代诗/古体诗/词/绝句/律诗）
2. 主题/意象？
3. 想要表达什么情感？
4. 多长？（几句/几段）

可选：
5. 需要押韵吗？
6. 有特定意象想用吗？（如：月亮、秋天、流水）

### F. 技术文章
必问：
1. 技术主题？
2. 面向什么水平的读者？（新手入门/中级开发者/高级/架构师）
3. 什么类型？（教程/分析/科普/架构文档）
4. 需要包含代码吗？

可选：
5. 需要图解/示意图吗？
6. 参考技术栈？（如：React/Python/Go）
7. 长度偏好？

## 五、输出格式

生成内容后，以统一格式呈现：

```
## {标题}

// 副标题（可选）

---

### 正文

{生成的内容}

---

**字数统计**：约 {xxx} 字
**阅读时间**：约 {x} 分钟

---

// 如有需要，可以继续优化：
// - "换个风格"
// - "缩短/加长"
// - "语气改活泼一点"
// - "重新生成"
```
