# Writing Skill V3 设计：用户自定义风格参考

**日期**：2026-02-26
**主题**：用户自定义风格参考功能

---

## 一、概述

用户可以提供自己写的文章作为风格样本，AI 分析这些文章的风格特点，然后生成/润色时模仿这种风格，减少"AI 感"。

---

## 二、应用场景

1. **写作时参考风格** - 用户想写新文章时，提供样本让 AI 模仿风格
2. **润色时参考风格** - 用户有初稿，提供样本让 AI 按该风格润色

---

## 三、风格分析要素

### 核心要素（必分析）
- **用词习惯** - 专业术语/口语化/接地气/文言化
- **句子长短** - 长句多/短句多/长短交替
- **段落结构** - 段落长度、层次安排

### 扩展要素（如有）
- **语气特点** - 严肃/轻松/俏皮/温暖/犀利
- **开头方式** - 直入主题/故事引入/提问引入/结论先行
- **结尾方式** - 总结/升华/开放/互动/金句点睛
- **叙事节奏** - 快/慢/张弛有度
- **个人特色** - 特色词/口头禅/习惯表达

---

## 四、输入方式

| 类型 | 识别方式 | 处理方式 |
|------|----------|----------|
| **直接粘贴** | 用户复制文章内容 | 直接分析 |
| **文件路径** | 本地路径格式 | 读取文件内容 |
| **仓库地址** | GitHub URL | 获取文件内容 |

---

## 五、交互流程

### 写作场景

```
用户：帮我写一篇公众号文章，关于AI的
技能：好的。你有自己的写作风格想让我参考吗？
      可以提供1-3篇你之前写的文章，我会模仿你的风格。
用户：好，我给你（粘贴文章/给文件/给仓库）
技能：收到！我来分析一下你的风格特点...

      === 风格分析结果 ===
      核心特点：
      - 用词：接地气，常用口语化表达
      - 句式：短句为主，节奏明快
      - 结构：总分总结构，层次清晰

      扩展特点：
      - 语气：轻松俏皮，有点幽默
      - 开头：直入主题
      - 结尾：互动引导
      - 个人特色：常用"真的"、"说实话"

      风格总结：你的风格属于轻松亲切接地气型，适合公众号和社交媒体。

      === 分析结束 ===

      好的，我现在按这个风格帮你写...
```

### 润色场景

```
用户：帮我润色这篇文章（粘贴文章）
技能：想要用什么风格润色？
用户1：参考我之前写的XX文章（提供样本）
用户2：换成更轻松的风格
技能（用户1）：好的，请提供风格参考文章...
      [用户提供后]
      我来分析一下你的风格特点...
      现在按这个风格帮你润色...

技能（用户2）：好的，帮你改成轻松风格...
```

```
### 扩展特点

- 节奏：{xxx}
- 个人特色：{xxx}

{一句话总结风格特点}
```

### 风格分析 prompt 模板

请分析以下文章的风格特点：

文章内容：
{文章内容}

请分析以下要素：

**核心要素（必分析）：**
1. 用词习惯 - 这篇文章用什么类型的词？专业/口语/接地气/文言？
2. 句子长短 - 长句多还是短句多？还是交替？
3. 段落结构 - 段落长度如何？层次怎么安排？

**扩展要素（如有）：**
4. 语气特点 - 严肃/轻松/俏皮/温暖/犀利？
5. 开头方式 - 直入主题/故事引入/提问引入/结论先行？
6. 结尾方式 - 总结/升华/开放/互动/金句点睛？
7. 叙事节奏 - 快/慢/张弛有度？
8. 个人特色 - 有没有什么特色词或口头禅？

请用 JSON 格式输出：
```json
{
  "core": {
    "vocabulary": "用词特点描述",
    "sentence": "句式特点描述",
    "structure": "结构特点描述"
  },
  "extended": {
    "tone": "语气特点描述",
    "opening": "开头特点描述",
    "closing": "结尾特点描述",
    "rhythm": "节奏特点描述",
    "personal": "个人特色描述"
  },
  "summary": "一句话风格总结"
}
```

## 七、集成位置

### 1. 写作模块 - 新增"风格参考"选项

在每个写作类型的追问流程中增加：

```
可选：
N. 有自己的写作风格想让我参考吗？（提供1-3篇你之前写的文章）
   - 可以粘贴文章/提供文件路径/提供仓库地址
   - 我会分析风格后按该风格写作
```

### 2. 润色模块 - 新增"参考风格"选项

在润色类型选择后增加：

```
风格参考方式：
1. 参考风格样本 - 提供你之前写的文章，我按该风格润色
2. 指定风格 - 直接选择目标风格（严肃/轻松/幽默等）
```

### 3. 新增"风格样本分析"模块

```
## E. 风格样本分析模块

### E1. 触发场景

当用户：
- 在写作时说"参考我的风格"、"按我的风格写"
- 在润色时说"参考我之前的文章"
- 直接提供文章内容说"按这个风格"

### E2. 收集流程

1. 询问用户提供方式：
   - 直接粘贴文章
   - 提供文件路径
   - 提供仓库地址

2. 获取内容后进行分析

3. 展示分析结果供用户确认

4. 确认后应用到写作/润色

### E3. 限制

- 样本数量：1-3篇
- 每篇长度：建议 500-3000 字
- 超出范围可以只分析部分内容
```
