# naming - 命名技能

> 通用 AI 命名技能，为任意场景生成合适的名称

## 功能

通过对话式交互，帮助用户为各种场景生成合适的名称。支持 26+ 种命名场景，每个场景都有针对性的追问逻辑，生成前会询问关键信息以确保命名精准。

## 支持场景

### 生活类
- 人名（中文名/英文名/花名）
- 宝宝小名（乳名）
- 宠物名
- 网名/ID
- 植物名（花名/树名）

### 工作类
- 项目/产品命名
- 代码变量/函数/类命名
- 文件/文件夹命名
- 品牌/公司名
- 域名
- 商标/Logo名
- 公众号/自媒体名称
- 小红书/抖音/B站账号名
- 短视频标题/脚本标题
- 淘宝店铺名
- App应用名
- 菜名/餐厅名
- 节目/栏目名
- 活动/赛事名

### 创意类
- 小说/角色名
- 书名/小说篇名
- 音乐/艺术作品名
- 游戏ID/昵称

### 语言类
- 日语/韩语名字
- 粤语/闽南语名字

## Usage

```bash
/spencergo:naming
```

## 对话流程

1. **识别场景** - 判断用户想要为什么类型的事物起名
2. **选择分支** - 从对应的追问分支开始
3. **依次追问** - 一次只问一个问题，等待用户回答后再问下一个
4. **生成名称** - 信息收集完后生成候选（默认 8 个）
5. **展示结果** - 以表格形式展示，包含名称和解释
6. **等待选择** - 询问用户更喜欢哪个，或有什么修改意见

## 功能特性

### 多种输入方式
- 描述式 - 描述一个想法/概念
- 关键词式 - 提供关键词组合
- 参考式 - 给参考名称，生成类似风格

### 丰富的风格选项
- 古典诗词、古风古韵
- 现代简约、科技感
- 二次元、萌系
- 文艺清新、创意独特
- 等等...

### 调性选择
- 写实、天马行空、史诗感
- 浪漫、悬疑、黑暗
- 热血、治愈、幽默
- 仙气、武侠、霸总
- 等等...

### 微调支持
- 换风格
- 换语言（中/英/双语）
- 加字/减字
- 调整方向

### 特殊功能
- 名字评分（寓意、音韵、独特性等）
- 名字匹配度分析
- 查重检查建议
- 方言名字支持
