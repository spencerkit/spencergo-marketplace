# 命名技能 (Naming Skill)

## 使用方法

当用户需要为某个事物起名时，使用这个skill。支持以下场景：
- 项目/产品命名
- 代码变量/函数/类命名
- 文件/文件夹命名
- 人名（中文名/英文名/花名）
- 宝宝小名（乳名）
- 宠物名
- 小说/角色名
- 品牌/公司名
- 书名/小说篇名
- 音乐/艺术作品名
- 游戏ID/昵称
- 网名/ID
- 公众号/自媒体名称
- 小红书/抖音/B站账号名
- 短视频标题/脚本标题
- 淘宝店铺名
- App应用名
- 域名
- 商标/品牌Logo名
- 菜名/餐厅名
- 节目/栏目名
- 活动/赛事名
- 日语/韩语名字
- 粤语/闽南语名字
- 植物名（花名/树名）
- 其他任意场景

## 询问流程（必须执行）

**第一步：识别场景类型**

首先判断用户想要为什么类型的事物起名，然后根据场景选择对应的追问分支：

### 场景类型及追问分支

#### A. 项目/产品命名
**追问问题（依次问）：**
1. 这个项目/产品的核心功能是什么？
2. 目标用户是谁？
3. 想要什么风格的命名？
   - 科技感：简洁、英文、国际化
   - 中国风：古典、诗词、典故
   - 亲切感：温暖、易懂、接地气
   - 高端大气：专业、权威、有辨识度
   - 创意独特：新颖、与众不同
   - 动物/自然：借助自然元素
4. 有什么关键词想要体现？（可选）
5. 有没有参考的名字风格？（可选）
6. 需要中文名、英文名还是中英双语？（默认双语）

#### B. 代码命名
**追问问题（依次问）：**
1. 这个变量/函数/类/常量的用途是什么？
2. 使用的编程语言是什么？（用于确定命名风格）
3. 有什么特定的命名风格要求吗？（可选）
4. 项目中有没有类似的命名可以参考？（可选）

#### C. 文件/文件夹命名
**追问问题（依次问）：**
1. 这个文件/文件夹的主要功能是什么？
2. 文件类型/文件夹用途是什么？（如.ts, .tsx, .py, .js等，或用于存放什么）
3. 有什么特定的命名风格要求吗？（可选）

#### D. 人名（中文名/英文名/花名）
**追问问题（依次问）：**
1. 是男孩名、女孩名还是中性名？
2. 有什么寓意或期望想体现在名字里？
3. 家族辈分用字？（仅中文名，可选）
4. 出生季节？（春/夏/秋/冬，可选，用于五行或季节意象）
5. 有什么属相/生肖偏好？（可选，如龙、兔等）
6. 有星座偏好吗？（可选）
7. 喜欢什么风格？
   - 中文名风格：传统保守/现代时尚/独特创意/自然清新/古典诗词/典故成语/古风古韵
   - 英文名风格：经典优雅/现代简约/复古怀旧/自然清新/独特个性
8. 想要什么调性？（可选）
   - 写实：贴近生活，真实自然
   - 文艺：优雅、有内涵、气质
   - 仙气：空灵、脱俗、意境
   - 二次元：可爱、萌系、动漫感
   - 武侠：江湖气息、豪爽大气
   - 霸总：总裁范、高冷贵气
   - 甜美：温柔、可爱、少女感
   - 硬朗：阳刚、力量、坚毅
   - 神秘：低调、内敛、难测
   - 复古：怀旧、经典、有年代感
9. 如果偏好古典风格，想要什么类型的灵感来源？（古诗词/成语典故/楚辞诗经/唐诗宋词/散文小说/历史人物）
10. 姓氏是什么？（可选，用于组合格式）

#### E. 宠物名
**追问问题（依次问）：**
1. 是什么类型的宠物？（猫、狗、鸟类、鱼、爬行动物、兔子、仓鼠等）
2. 宠物的性别是？（公/母/未知）
3. 有什么特征想体现在名字里？（外观、性格、品种）
4. 名字来源偏好？（可选）
   - 食物：糖果、汤圆、奶茶
   - 动漫：常用动漫角色名
   - 叠字：豆豆、苗苗
   - 英文：TOM、Lucy
   - 自然：星星、月亮
   - 无特定偏好
5. 喜欢什么风格？（可爱萌系/酷帅个性/食物系/自然系/简单直白）
6. 需要几个候选？（默认8个）

#### F. 小说/角色名
**追问问题（依次问）：**
1. 是主角、配角还是反派？
2. 是什么类型的故事/世界观？（仙侠/科幻/现代/西幻/历史/悬疑/都市/校园/军事/商战）
3. 角色有什么特点或背景想体现在名字里？
4. 想要什么调性？（可选）
   - 写实：贴近生活，真实自然，符合现实逻辑
   - 天马行空：创意无限，不受束缚，想象力丰富
   - 二次元：动漫风格，可爱萌系，轻小说风
   - 史诗感：宏大叙事，庄严肃穆，历史厚重
   - 浪漫：甜蜜、唯美、情感丰富
   - 悬疑：神秘、紧张、引人好奇
   - 黑暗：阴郁、压抑、反派感
   - 热血：激昂、励志、战斗感
   - 治愈：温暖、温柔、疗愈感
   - 幽默：轻松、诙谐、搞笑
   - 复古：怀旧风格，有年代感
   - 未来感：科技、前沿、赛博朋克
5. 名字需要体现时代背景吗？（如古代/未来/特定年代）
6. 姓氏需要吗？（如萧炎、叶凡等）

#### G. 品牌/公司名
**追问问题（依次问）：**
1. 这个品牌/公司的核心业务是什么？
2. 目标受众是谁？
3. 品牌调性是什么？（高端大气/亲和力/科技感/自然清新/复古怀旧/文艺小众/简约现代/中国风古典）
4. 创始人或团队有什么特点想体现？（如创始人姓名风格、团队理念等）
5. 品牌成立年份？（可选，用于年份相关命名）
6. 想要什么风格的命名？
   - 现代简约：简短有力，易于传播
   - 古典诗词：出自诗词典故，有文化底蕴
   - 英文直译：直接翻译核心业务或价值观
   - 文字游戏：谐音、双关、创意组合
   - 自然意象：山川草木、日月星辰
   - 抽象概念：美好愿景或价值观
7. 有什么关键词想要体现？（可选）
8. 需要中文名、英文名还是中英双语？（默认双语）
9. 域名是否需要考虑？（可选）

#### H. 书名/小说篇名
**追问问题（依次问）：**
1. 是什么类型的作品？（长篇小说/短篇小说/散文集/诗集/剧本/漫画/轻小说等）
2. 作品的主题或核心内容是什么？
3. 想要什么风格的书名？
   - 古典诗词：出自诗词，意境深远
   - 现代诗歌：诗意、抽象、意象
   - 小说叙事：故事感强，引起好奇
   - 简短有力：直击主题，易于传播
   - 悬念型：引发好奇心，想看内容
   - 情感型：温暖、悲伤、治愈等情感词
   - 人物/地名：以人物或地名命名
   - 意象型：借助具体事物象征主题
4. 想要什么调性？（可选）
   - 写实：贴近生活，揭示社会现实
   - 天马行空：奇幻、想象力丰富
   - 二次元：轻小说、动漫风格
   - 史诗感：宏大叙事，震撼人心
   - 浪漫：甜蜜、唯美、爱情为主
   - 悬疑：紧张、烧脑、推理
   - 黑暗：深沉、压抑、现实
   - 热血：激情、战斗、成长
   - 治愈：温暖、疗愈、温柔
   - 幽默：轻松、搞笑、吐槽
   - 复古：怀旧、有年代感
   - 未来感：科幻、前沿、赛博
5. 书名长度有偏好吗？（简短/中等/诗意长句）
6. 需要什么语言？（中文/英文/双语）
7. 有没有参考的书名风格？（可选）

#### I. 音乐/艺术作品名
**追问问题（依次问）：**
1. 是什么类型的作品？（歌曲、专辑、画作、摄影作品、设计作品、小说、散文、诗歌、游戏、动漫等）
2. 作品的风格或情感基调是什么？（欢快、悲伤、激昂、宁静、神秘、浪漫、史诗、治愈等）
3. 想要什么风格的命名？
   - 现代简约：简短有力，直击人心
   - 古典诗词：出自诗词典故，意境深远
   - 意识流：抽象、意象、碎片化
   - 叙事性：有故事感，让人产生联想
   - 文字游戏：谐音、双关、创意组合
   - 自然意象：山川草木、日月星辰、风雨云雾
   - 情感共鸣：温暖、孤独、自由、希望
4. 想要什么调性？（可选）
   - 写实：纪实、客观、现实主义
   - 天马行空：奇幻、超现实、梦境感
   - 二次元：动漫风格、萌系、可爱
   - 史诗感：宏大、震撼、史诗级
   - 浪漫：甜蜜、唯美、爱情向
   - 悬疑：神秘、紧张、推理向
   - 黑暗：深沉、压抑、成人向
   - 热血：激情、战斗、成长向
   - 治愈：温暖、疗愈、温柔向
   - 幽默：轻松、搞笑、欢乐向
   - 复古：怀旧、年代感、复古风
   - 未来感：科幻、前沿、赛博朋克
5. 有什么主题或意象想体现在名字里？（可选）
6. 名字长度有偏好吗？（简短有力/中等/诗意长句）
7. 需要什么语言？（中文/英文/双语）

#### J. 游戏ID/昵称
**追问问题（依次问）：**
1. 是游戏ID还是游戏昵称？
2. 玩的是什么类型的游戏？（MOBA/FPS/MMO/休闲/卡牌/射击/竞技/二次元等）
3. 想要什么风格的ID？
   - 简短有力：好记易打
   - 文艺诗意：有意境有内涵
   - 二次元：动漫风格
   - 炫酷拽：霸气侧漏
   - 搞怪有趣：幽默风趣
   - 数字字母组合：英文+数字
   - 古风武侠：江湖气息
4. 有什么关键词想体现？（如喜欢的角色、动物、元素等）
5. 有没有参考的ID风格？（可选）
6. 需要什么语言？（中文/英文/数字）

#### K. 公众号/自媒体名称
**追问问题（依次问）：**
1. 这个公众号/自媒体的核心内容是什么？（如情感、职场、科技、美食、旅行等）
2. 目标受众是谁？
3. 想要什么风格的名称？
   - 通俗易懂：接地气，易传播
   - 文艺小众：有格调，不随大流
   - 垂直专业：体现专业性
   - 人格化：以人物命名
   - 机构感：公司、团队、工作室
   - 中国风：古典诗词、典故
4. 有什么关键词想要体现？（可选）
5. 需要中文名、英文名还是中英双语？（默认中文）
6. 域名或相关平台用户名是否需要考虑？（可选）

#### L. 短视频标题/脚本标题
**追问问题（依次问）：**
1. 视频的主题/内容是什么？
2. 目标平台是什么？（抖音/B站/视频号/小红书/YouTube等）
3. 想要什么风格的标题？
   - 标题党：夸张、引发好奇
   - 干货型：实用、有价值
   - 情感共鸣：引发情感触动
   - 故事型：有故事感
   - 疑问型：提问引发思考
   - 反差型：出人意料
   - 盘点型：排行榜、清单
   - 科普型：知识讲解
4. 标题长度有偏好吗？（简短/中等/详细）
5. 需要什么语言？（中文/英文/双语）

#### M. 域名
**追问问题（依次问）：**
1. 域名的用途是什么？（网站/项目/产品/品牌）
2. 核心业务或关键词是什么？
3. 想要什么类型的域名？
   - 单词域名：简短，如 apple.com
   - 组合域名：两个词组合
   - 品牌名+后缀：如 nameapp.com
   - 纯数字：如 123.com
   - 谐音域名：英文音译
   - 行业域名：行业词+通用词
4. 需要什么后缀？（.com/.cn/.io/.net等，.com优先）
5. 预算范围？（可选，影响选择）

#### N. 商标/品牌Logo名
**追问问题（依次问）：**
1. 品牌/产品的核心业务是什么？
2. 目标市场是？（国内/国际）
3. 想要什么风格的Logo名？
   - 文字型：纯文字，简洁
   - 字母型：首字母缩写
   - 图形+文字：图文结合
   - 抽象图形：不直接体现业务
   - 具象图形：直接体现业务
4. 品牌调性是什么？（高端/亲和/科技/自然/复古等）
5. 颜色偏好？（可选）
6. 有没有参考的Logo风格？（可选）

#### O. 菜名/餐厅名
**追问问题（依次问）：**
1. 是餐厅名还是菜名？
2. 是什么菜系？（中餐/西餐/日料/韩餐/东南亚/融合菜/川菜/粤菜等）
3. 想要什么风格的名称？
   - 传统老字号：有历史感
   - 文艺清新：有格调
   - 江湖气息：武侠风
   - 地域特色：体现地方
   - 人名/故事：以人名或故事命名
   - 食材为主：突出食材
   - 意境型：有诗意
4. 餐厅定位是什么？（高端/中端/平价/快餐/私房菜）
5. 有什么特色想体现？（可选）
6. 需要中文名、英文名还是中英双语？

#### P. 节目/栏目名
**追问问题（依次问）：**
1. 是什么类型的节目？（综艺/访谈/纪录片/电台/直播/短视频栏目等）
2. 节目的核心内容或主题是什么？
3. 目标受众是谁？
4. 想要什么风格的名称？
   - 简单直接：易懂易记
   - 悬念型：引发好奇
   - 故事型：有叙事感
   - 情感型：温暖/治愈
   - 搞笑型：幽默风趣
   - 专业型：权威感
   - 人格化：以主持人/嘉宾命名
   - 主题词+节目类型：如《XX说》
5. 想要什么调性？（正式/轻松/严肃/活泼）
6. 有没有参考的节目名？（可选）

#### Q. 活动/赛事名
**追问问题（依次问）：**
1. 是什么类型的活动/赛事？（体育/电竞/商业/文化/公益/年会/发布会等）
2. 活动的规模是？（国际/国内/地区/公司内部）
3. 核心主题或内容是什么？
4. 想要什么风格的名称？
   - 简洁有力：易传播
   - 高端大气：彰显规格
   - 主题突出：体现活动内容
   - 创意独特：与众不同
   - 数字+主题：如XX杯、XX赛
   - 年份相关：包含年份
5. 需要中英文名吗？（默认中文）
6. 域名或相关账号名是否需要考虑？（可选，如赛事官网）

#### R. 日语/韩语名字

   - 日语：传统和风/现代时尚/动漫感/汉字名/片假名
   - 韩语：传统韩风/现代简约/韩流明星感/汉字意
5. 姓氏是什么？（可选，用于组合格式）
6. 汉字形式还是假名/谚文形式？（如中文"田中"对应日文"たなか"或韩文"전"）

2. 账号的核心内容是什么？（美妆/穿搭/美食/旅行/数码/职场/情感/知识等）
3. 想要什么风格的账号名？
   - 人格化：以人物命名，如"XX的日常"
   - 内容垂直：直接体现内容领域
   - 创意独特：与众不同，有辨识度
   - 简洁易记：短小精悍
   - 搞笑有趣：幽默风趣
   - 文艺清新：有格调
4. 有没有参考的账号风格？（可选）
5. 需要注意平台是否有特殊限制？（如字数、特殊字符等）

   - 通俗易懂：接地气

   - 高端大气：专业感
   - 亲切可爱：亲和力

5. 商标是否需要考虑？（可选）

#### U. App应用名

1. App的核心功能是什么？

## 命名原则

**文件命名：**

## 工作流程

**重要：必须按照以下流程执行**

1. **识别场景** - 根据用户的初始请求判断场景类型
2. **选择分支** - 从对应的追问分支开始
3. **依次追问** - 一次只问一个问题，等待用户回答后再问下一个
   - **可选问题**：用户可以回答"跳过"或"不用了"直接进入下一题
   - **并行处理**：如果用户一次回答了多个问题，可以同时处理并继续问下一个
4. **生成名称** - 信息收集完后生成候选
5. **展示结果** - 以表格形式展示，包含名称和解释
6. **等待选择** - 询问用户更喜欢哪个，或有什么修改意见
7. **微调支持** - 用户选择后可继续优化（换风格、换语言、加字等）

### 追问逻辑优化

**跳过机制：**
- 标注为"可选"的问题，用户可以回答"跳过"、"不用"、"下一题"等跳过
- 跳过后续可选问题后，直接进入生成环节

**并行处理：**
- 如果用户一次回答了多个问题（如"我叫张三，想给儿子起名，男孩"），可以同时提取：
  - 场景类型：人名
  - 姓氏：张
  - 性别：男孩
- 然后继续问下一个未回答的必要问题

**追问技巧：**
- 尽量用选择题形式，减少用户思考负担
- 根据用户回答灵活调整问题顺序
- 可以在问题中加入简单的寒暄，让对话更自然

### 追问逻辑示例

**场景：用户说"帮我起个名字"**

1. 先问："你是要起什么类型的名字？比如项目名、代码名、人名、宠物名、品牌名、小说角色名、游戏ID等？"

2. 用户回答后，选择对应分支：
   - 如果用户说"一个产品名" → 走 A.项目/产品命名 分支
   - 如果用户说"帮我家猫起名" → 走 E.宠物名 分支
   - 如果用户说"起个人名" → 走 D.人名 分支
   - 等等...

3. 按分支顺序追问，根据用户回答灵活调整

**跳过示例：**
```

### 名字禁忌（必读）

起名时需要注意以下禁忌：

**中文名禁忌：**
- 谐音歧义：避免与不雅词汇谐音（如"史珍香"、"杜子腾"等）
- 生僻字：避免过于复杂的字，影响日常使用
- 多音字：避免容易读错的字
- 负面含义：避免消极、不吉利的字义
- 祖先名：避免与祖辈名字重复（部分地区习俗）
- 同音不同字：注意同音词的歧义

**英文名禁忌：**
- 奇怪含义：避免有不良含义的单词
- 难以发音：避免太长的名字
- 文化禁忌：避免在目标国家/文化中有负面含义的名字
- 与品牌冲突：避免与知名品牌重名

**品牌名禁忌：**
- 商标侵权：避免与已有商标近似
- 行业通用词：避免过于通用的词汇
- 政治敏感：避免涉及政治元素
- 宗教禁忌：避免涉及宗教元素
