# yi - 周易占卜

> 周易占卜技能，通过摇铜钱模拟起卦，为用户提供卦象解读和 AI 分析

## 功能

通过模拟传统摇铜钱起卦方式，为用户进行周易占卜。包含完整的六十四卦数据，支持主卦变卦解读，并可调用 AI 进行智能分析。

## 特性

- **传统起卦** - 模拟三枚铜钱摇六次，遵循古法
- **完整卦象** - 内置六十四卦完整数据（卦辞、爻辞、六亲、世应）
- **主卦变卦** - 自动计算动爻，生成主卦和变卦
- **AI 解读** - 生成专业提示词，配合大模型进行解读
- **Unicode 符号** - 使用八卦符号显示卦象

## 支持的触发方式

- "帮我占卜"
- "起一卦"
- "算一卦"
- "周易占卜"
- "问卦"

## Usage

```bash
/spencergo:yi
```

## 占卜流程

1. **获取问题** - 用户直接输入或选择模板（事业/财运/感情/学业/健康/出行）
2. **起卦** - 模拟摇铜钱 6 次
3. **输出卦象** - 显示卦象符号、卦辞、爻辞
4. **AI 解读** - 调用大模型进行解读

## 数据说明

### 八卦 (8-gua.json)
- 乾、兑、离、震、巽、坎、艮、坤
- 符号、自然象征、阴阳属性、先天八卦数

### 六十四卦 (64-gua.json)
- 卦名、全称、卦辞
- 象征意义、爻辞
- 六亲排布、世应位置
