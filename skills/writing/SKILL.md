# 写作技能 (Writing Skill)

## 使用方法

当用户需要写作帮助时，使用这个技能。支持以下类型：
- 内容创作：公众号/博客、小红书、微博、短视频脚本、B站脚本
- 创意写作：故事/小说、诗歌
- 技术文章：技术教程、技术分析、技术科普、架构文档

## 使用方式

```
/写作
```

或直接描述需求，如：
- "帮我写一篇公众号文章"
- "写一个科幻短故事"
- "一篇Python教程"

## 技能分支

根据用户需求自动识别写作类型，进入对应的追问流程。

---

## A. 内容创作分支

### A1. 公众号/博客文章

**追问流程：**
1. 文章主题是什么？
2. 目标读者是谁？
3. 想要什么风格？（严肃正式/轻松活泼/幽默风趣/温暖治愈/犀利深刻）
4. 大概需要多长？（1000字/2000字/3000字+）

可选：
5. 有什么特别想表达的观点？
6. 需要加入案例或故事吗？
7. 语言偏好？（中文/英文/双语）

**生成 prompt 模板：**
请生成一篇公众号文章：

主题：{主题}
目标读者：{读者}
风格：{风格}
语言：{语言}
字数：约{字数}字
结构：{结构}
开头：{开头方式}
结尾：{结尾方式}
语气：{语气}

要求：
1. 文章结构清晰，层次分明
2. 语言符合指定风格和语气
3. 内容有深度，能给读者带来价值
4. 开头能吸引读者注意
5. 结尾有记忆点

---

### A2. 小红书/社交媒体

**追问流程：**
1. 笔记的核心话题/主题？
2. 目标人群？（如：职场女生/大学生/新手妈妈）
3. 想要什么风格？
   - 干货型：实用、有价值
   - 情感型：引发共鸣
   - 种草型：推荐好物
   - 故事型：分享经历
4. 需要几个部分/几点？

可选：
5. 想要什么语气？（亲切/专业/俏皮）
6. 需要加emoji或话题标签吗？

**生成 prompt 模板：**
请生成一篇小红书笔记：

主题：{主题}
目标人群：{人群}
风格：{风格}
结构：{结构}
语气：{语气}
字数：约{字数}字

要求：
1. 语言生动，符合小红书风格
2. 适当使用 emoji 增加互动感
3. 内容有价值，能引起共鸣
4. 添加合适的热门话题标签

---

### A3. 短视频脚本

**追问流程：**
1. 视频主题？
2. 时长？（15秒/30秒/1分钟/5分钟）
3. 内容类型？
   - 知识科普
   - 剧情故事
   - 好物推荐
   - 搞笑段子
   - 情感表达
4. 目标受众？

可选：
5. 需要分镜吗？
6. 旁白还是对话形式？

**生成 prompt 模板：**
请生成一个短视频脚本：

主题：{主题}
时长：{时长}
内容类型：{类型}
目标受众：{受众}
形式：{旁白/对话/分镜}

要求：
1. 节奏紧凑，符合时长要求
2. 开头抓住注意力
3. 内容有价值或娱乐性
4. 结尾引导互动

---

### A4. B站视频脚本

**追问流程：**
1. 视频主题？
2. 视频时长？（5分钟/10分钟/15分钟）
3. 内容类型？
   - 知识讲解
   - 测评体验
   - 故事叙述
   - 观点表达
4. 目标受众？
5. 需要几个部分？

可选：
6. 需要的语言风格？（严肃/活泼/专业/搞笑）

---

## B. 创意写作分支

### B1. 故事/小说

**追问流程：**
1. 什么类型的故事？
   - 都市 / 校园 / 悬疑 / 科幻 / 奇幻 / 历史 / 武侠 / 爱情
2. 主要人物是谁？（或想要什么特点的人物）
3. 故事背景？（现代/古代/未来/异世界）
4. 大概多长？（短篇/微小说/中篇）
5. 风格调性？
   - 热血 / 治愈 / 虐心 / 轻松 / 深刻 / 黑暗 / 甜宠

可选：
6. 需要什么结局？（圆满/开放/悲剧）
7. 有特定的情节元素想加入吗？

**生成 prompt 模板：**
请写一个{类型}故事：

背景：{背景}
主要人物：{人物}
长度：{长度}
风格：{风格}
结局：{结局}

要求：
1. 人物性格鲜明，有成长弧光
2. 情节合理，有张力
3. 环境描写恰当，营造氛围
4. 语言符合风格调性

---

### B2. 诗歌

**追问流程：**
1. 什么类型的诗歌？
   - 现代诗 / 古体诗 / 词 / 绝句 / 律诗
2. 主题/意象？
3. 想要表达什么情感？
4. 多长？（几句/几段）

可选：
5. 需要押韵吗？
6. 有特定意象想用吗？（如：月亮、秋天、流水）

**生成 prompt 模板：**
请写一首{类型}诗：

主题：{主题}
情感：{情感}
长度：{长度}
押韵：{是/否}
意象：{意象}

要求：
1. 意象丰富，意境深远
2. 情感真挚，有感染力
3. 语言优美，韵律和谐（如需押韵）

---

## C. 技术文章分支

### C1. 技术教程

**追问流程：**
1. 技术主题？
2. 面向什么水平的读者？（新手入门/中级开发者）
3. 需要包含代码吗？
4. 大概多长？

可选：
5. 参考技术栈？（如：React/Python/Go）
6. 需要图解/示意图吗？

---

### C2. 技术分析

**追问流程：**
1. 技术主题？
2. 分析深度？（入门/进阶/深度）
3. 目标读者？
4. 需要包含代码示例吗？

---

### C3. 技术科普

**追问流程：**
1. 科普主题？
2. 目标受众？（完全小白/有基础/非技术人员）
3. 想要什么风格？（通俗易懂/幽默风趣/严肃专业）
4. 大概多长？

---

### C4. 架构文档

**追问流程：**
1. 系统名称/主题？
2. 面向什么读者？（技术团队/管理层/业务方）
3. 需要包含哪些部分？（概述/模块设计/技术选型/部署方案）
4. 详细程度？（简略/详细）

## 输出格式

生成内容后，以统一格式呈现：

```
## {标题}

// 副标题（可选）

---

### 正文

{生成的内容}

---

**字数统计**：约 {xxx} 字
**阅读时间**：约 {x} 分钟

---

// 如有需要，可以继续优化：
// - "换个风格"
// - "缩短/加长"
// - "语气改活泼一点"
// - "重新生成"
```

---

## 追问技巧

1. **一次只问一个问题**，等待用户回答后再问下一个
2. **优先用选择题**，减少用户思考负担
3. **可选问题标注清楚**，用户可以跳过
4. **并行处理**：如果用户一次回答了多个问题，同时处理
5. **记住上下文**：之前的回答自动带入后续问题

---

## 优化反馈

生成初稿后，提供以下优化选项：
- 换个风格
- 缩短/加长
- 调整语气
- 重新生成
- 修改具体部分
