# Sample Product / Project Evaluation Report

Use this as a shape reference for “值不值得做” or project-evaluation research.
Do not copy the wording blindly.

## 1. 标题
《某项目/某产品方向评估报告》

## 2. 执行摘要
- 当前值不值得继续看
- 问题是出在需求、供给、变现，还是执行
- 现阶段最该验证什么

## 3. 研究问题
示例：
- 这个项目方向是否值得启动验证？
- 现在的问题是没有需求，还是差异化太难？

## 4. 核心结论
这里不要空话，要明确：
- 是“值得试”
- 还是“只值得继续摸底”
- 还是“暂时不建议做”

## 5. 核心依据
重点看：
- 用户问题是否真实
- 是否已有替代方案
- 差异化难度高不高
- 变现逻辑站不站得住
- 执行门槛高不高

## 6. 多维度分析
建议覆盖：
- 用户问题
- 替代方案
- 差异化难度
- 变现路径
- 执行门槛
- 风险
- 切入机会

## 7. 不确定性与待补充
特别要标：
- 付费意愿是否已有证据
- 获客难度是否已有证据
- 替代方案强度是否已查清

## 8. 理性建议
建议示例：
- 先做轻量验证，不建议直接重投入。
- 如果继续推进，优先补用户访谈或真实付费证据。
- 当前最大不确定性在差异化，而不是话题热度。

## 9. 来源说明
列出真正支撑判断的来源，而不是把所有搜索结果都堆上去。
