# Component Layout Strategies

## 1. Goal

Use different component ordering depending on report type, so the delivery structure matches the user's actual decision need instead of forcing every report into one fixed layout.

---

## 2. Market / industry research layout

Best when the user needs:
- market orientation
- strategic positioning
- trend understanding

Recommended order:
1. executive summary
2. key takeaways strip
3. metric strip
4. decision panel
5. core conclusion
6. key evidence
7. dimension-based analysis
8. charts
9. uncertainty / missing evidence
10. risk vs action split
11. recommendations
12. sources

Why:
- market reports benefit from fast macro scanning before deep reading

---

## 3. Product / project evaluation layout

Best when the user needs:
- worth-doing judgment
- investment / effort decision support
- go / no-go style output

Recommended order:
1. executive summary
2. decision panel
3. key takeaways strip
4. core conclusion
5. risk vs action split
6. key evidence
7. dimension-based analysis
8. charts
9. uncertainty / missing evidence
10. recommendations
11. sources

Why:
- this report type is decision-first, so recommendation and risk need to surface earlier

---

## 4. Platform / content ecosystem layout

Best when the user needs:
- platform fit
- content opportunity
- audience appetite
- traffic / distribution understanding

Recommended order:
1. executive summary
2. key takeaways strip
3. decision panel
4. core conclusion
5. key evidence
6. dimension-based analysis
7. charts
8. risk vs action split
9. uncertainty / missing evidence
10. recommendations
11. sources

Why:
- platform reports are usually read for tactical opportunity and fit judgment, not just high-level macro scanning

---

## 5. General rule

Do not reorder for aesthetics only.
Reorder based on:
- what decision the user is making
- what the user needs to see first
- whether the report is orientation-first or action-first

---

## 6. Fallback

If the report type is mixed or unclear:
- use the market / industry layout for broad strategic reports
- use the product / project layout for decision-heavy reports
- use the platform / content layout for fit and opportunity reports
