# Topic Types

## 1. Goal

Classify the user's research request before choosing dimensions and search angles.

---

## 2. Main types

### A. Market / industry
Use when the user asks about a sector, market, category, or broad business area.
Examples:
- AI companion market
- cross-border pet supplies
- online education industry

### B. Product / project
Use when the user asks whether a specific product idea, service, or project direction is worth doing.
Examples:
- is陪诊师 worth doing
- should we build this SaaS idea
- does this project have room

### C. Platform / content ecosystem
Use when the user asks about a platform, content field, traffic environment, or ecosystem patterns.
Examples:
- 小红书家居内容生态
- 小红书情感赛道
- short drama traffic trends

### D. Concept / trend
Use when the user asks about an emerging concept, narrative, or trend.
Examples:
- AI agents trend
- creator economy shift
- virtual companion trend

### E. Audience / demand
Use when the user asks about user needs, audience appetite, pain points, or willingness to pay.
Examples:
- do users want this
- what pain points are strongest
- who would pay for this

### F. Business model / monetization
Use when the user asks how money is made, whether something can monetize well, or whether a model is viable.
Examples:
- can this monetize
- what is the business model
- is this scalable

---

## 3. Mixed requests

Some requests span multiple types.
If so, choose one primary type and note the secondary angle.
Example:
- “小红书家居内容生态和值不值得做”
  - primary: platform / content ecosystem
  - secondary: product / project opportunity

## 4. Output-template mapping

After classifying the topic, pick the matching output template:
- market / industry → `output-template-market.md`
- product / project → `output-template-project.md`
- platform / content ecosystem → `output-template-platform-content.md`

Then use the matching sample report shape when you need a fuller delivery:
- market / industry → `sample-market-report.md`
- product / project → `sample-project-report.md`
- platform / content ecosystem → `sample-platform-report.md`

If the request is mixed, use the primary type's template and add 1-2 lines for the secondary angle instead of switching templates halfway.
