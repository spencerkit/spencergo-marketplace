# Report Components

## 1. Goal

Turn the report from a styled document into a more productized research deliverable with reusable presentation components.

---

## 2. Recommended components

Use these when they improve decision clarity:
- key takeaways strip
- confidence / source-strength strip
- risk vs action split block
- quick decision panel
- KPI / metric summary row
- recommended next-step list

---

## 3. Component rule

Do not add components as decoration.
Each component must improve one of these:
- scan speed
- decision clarity
- evidence visibility
- recommendation usability

---

## 4. Priority order

For serious reports, use a report-type-specific layout when possible.
See `component-layout-strategies.md`.

If no specific layout applies, prefer this fallback order:
1. executive summary
2. key takeaways
3. conclusion / confidence
4. evidence
5. analysis
6. uncertainty / risks
7. actions / recommendations
8. sources

---

## 5. Flat design rule

Components should feel:
- flat
- modern
- readable on mobile
- professional rather than ornamental
