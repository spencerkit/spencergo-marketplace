# Chart Components

## 1. Goal

Provide a small set of clean, evidence-safe charts for research delivery.

---

## 2. Preferred first-wave chart types

Use these first because they cover many reports and can be rendered reliably as inline SVG:
- horizontal bar comparison
- simple trend line / point trend
- opportunity-risk matrix
- source-strength summary

---

## 3. Usage rule

Choose the simplest chart that clarifies the point.
Do not chart just because space exists in the report.

---

## 4. Data discipline

Every chart should have:
- a clear title
- labeled data meaning
- source status
- a note when values are estimated, partial, or incomplete

If the data is not reliable enough for visual comparison, do not chart it.

---

## 5. Rendering rule

Prefer inline SVG so the report stays single-file and crisp.
Use raster or embedded image fallbacks only when native SVG representation is not practical.
