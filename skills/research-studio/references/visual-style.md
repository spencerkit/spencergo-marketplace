# Visual Style

## 1. Goal

Make the report look like a polished research document rather than a casual note or a marketing poster.

---

## 2. Style direction

Use:
- restrained colors
- strong hierarchy
- generous whitespace
- readable typography
- clear cards and section breaks

Avoid:
- loud gradients
- excessive decoration
- dashboard clutter
- visual tricks that weaken readability

---

## 3. Recommended structure cues

Use visual hierarchy for:
- title and metadata
- executive summary
- key conclusion highlight
- evidence blocks
- warning / uncertainty blocks
- source notes

---

## 4. Tone alignment

The visual style should support a research tone:
- calm
- precise
- professional
- evidence-first

Use color to distinguish:
- main conclusions
- evidence notes
- analytical sections
- warnings / uncertainty
- recommendations / action blocks
- high-confidence or well-supported areas
- source documentation areas

The palette should feel more technological and professional than decorative.
Each major content block should have a stable color meaning rather than arbitrary decoration.
