# Advanced Chart Patterns

## 1. Goal

Extend the report with a few higher-value chart patterns while keeping the visuals evidence-safe and readable on a 750px mobile layout.

---

## 2. Recommended next chart types

Add these after the first-wave charts:
- stacked comparison bar
- timeline
- competitor landscape scatter / 2D map

---

## 3. Mobile constraint

Charts must remain readable inside a 750px report width.
Prefer fewer labels, shorter names, and cleaner annotation.
Do not overload the chart area.

---

## 4. Data rule

Advanced charts still follow the same evidence rule:
- sourced data only
- no decorative pseudo-precision
- no fake completeness
