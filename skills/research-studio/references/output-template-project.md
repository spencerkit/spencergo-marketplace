# Product / Project Output Template

Use when the topic is mainly about whether a product idea, project direction, or business concept is worth doing.

## Default compact structure

### 结论
One-line judgment on whether the direction looks worth testing, cautiously viable, or unattractive.

### 核心发现
- problem clarity
- user demand signal
- execution difficulty

### 多维度结果
- 用户问题：what real problem or desire exists
- 替代方案：what people already use instead
- 差异化难度：how hard it is to stand out
- 变现路径：how this could make money
- 执行门槛：what makes execution hard
- 风险：what could kill it early
- 机会：where the opening is if it exists

### 最大机会
Name the strongest reason to test it.

### 最大风险
Name the strongest reason it may fail.

### 适合怎么切入
Suggest a realistic entry angle or test path.

### 信息缺口
What still needs validation before a stronger judgment.

## What to emphasize

Emphasize:
- whether the problem is real
- whether users already have acceptable substitutes
- whether the team could actually execute
- whether monetization is believable

Do not confuse “interesting” with “worth doing.”
