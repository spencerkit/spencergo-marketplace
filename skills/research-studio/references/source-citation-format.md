# Source Citation Format

## 1. Goal

Make source status visible in the research output so the user can tell what is well-supported, weakly supported, or still missing.

---

## 2. Minimal rule

For important evidence, show at least one of these clearly:
- source name
- source type
- whether it is primary / official / secondary
- whether multiple sources support the same point

---

## 3. Suggested compact formats

Use short formats such as:
- 来源：官方公告
- 来源：公司公开资料（二手报道交叉验证）
- 来源：媒体报道，单一来源，置信度一般
- 来源：行业文章，未见一手数据，待补充验证

---

## 4. Missing-data rule

If a number, comparison, or factual point cannot be sourced clearly:
- do not invent it
- do not smooth over it with vague wording
- mark it as 待补充

---

## 5. Output discipline

Do not attach a citation to every trivial sentence.
Do attach source status to:
- key factual claims
- important comparisons
- central evidence behind the conclusion
- numbers that influence the recommendation
