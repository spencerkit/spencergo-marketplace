# Chart Rules

## 1. Goal

Use charts only when they clarify evidence.
Do not create charts as decoration.

---

## 2. Suitable chart types

Use charts for:
- time trends
- category comparison
- proportion / composition
- simple matrices
- ranked competitor or factor comparison

---

## 3. Prohibited chart behavior

Do not create charts when:
- the data is missing
- the data cannot be sourced clearly
- the comparison is mostly subjective
- the chart would imply false precision

If data is incomplete, show a text block or a clearly labeled 待补充 section instead.

---

## 4. Evidence display in charts

When useful, indicate:
- source status
- whether values are exact, approximate, or incomplete
- whether multiple sources support the comparison

---

## 5. Preferred rendering approach

Prefer lightweight inline SVG visuals for simple charts.
Use raster or embedded image fallbacks only when the chart or evidence visual cannot be represented cleanly in SVG.
