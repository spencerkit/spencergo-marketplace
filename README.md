# spencergo-marketplace

> Spencer's personal marketplace for Claude Code skills

个人维护的 Claude Code 插件市场，汇集生活工作中常用的 AI 技能。

## 安装

```bash
# 添加市场
/plugin marketplace add 你的用户名/spencergo-marketplace

# 安装 skill
/plugin install naming@你的用户名/spencergo-marketplace
```

## 可用 Skills

### naming - 命名技能

通用 AI 命名技能，为任意场景生成合适的名称。

**支持场景：**
- 项目/产品命名
- 代码变量/函数/类命名
- 文件/文件夹命名
- 人名（中文名/英文名/花名）
- 宝宝小名（乳名）
- 宠物名
- 小说/角色名
- 品牌/公司名
- 书名/小说篇名
- 音乐/艺术作品名
- 游戏ID/昵称
- 网名/ID
- 公众号/自媒体名称
- 小红书/抖音/B站账号名
- 短视频标题/脚本标题
- 淘宝店铺名
- App应用名
- 域名
- 商标/品牌Logo名
- 菜名/餐厅名
- 节目/栏目名
- 活动/赛事名
- 日语/韩语名字
- 粤语/闽南语名字
- 植物名（花名/树名）

**使用方式：**
```bash
/naming
```
